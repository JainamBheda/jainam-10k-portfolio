# Jainam Bheda — Portfolio

This is a static portfolio site built with Vite + React + Tailwind CSS and Framer Motion.

Quick start

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

Notes

- Tailwind dark mode uses the `class` strategy. Use the theme toggle in the navbar.
- Replace placeholder links (LinkedIn, GitHub, project GitHub links, LeetCode username) in the source files.
- Resume (placeholder) is in `public/Resume8_JainamBheda_SDE.pdf`. Replace with the real PDF for download.
